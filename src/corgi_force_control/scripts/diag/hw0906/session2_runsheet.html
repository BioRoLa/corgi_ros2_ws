CELLS

The matrix — one command per cell

Args verified 2026-09-01 against sweep_cl_track.sh's composition and gslip_pronk.launch.py. All radians, all with decimal points. k_acker_yaw/d_acker_yaw launch defaults are 0.0 — omit them and the CL cell runs feedforward-only with no loop. gamma_acker_hi defaults to 15°, so the λ15/λ20 cells must raise it; steer_limit defaults to 8°, so the diff arm must pass 12°.

Control structure — what closes the loop in each cell (log §237)

lam_cmd = −sign(turn_rate)·ff  +  k_acker_yaw·yaw_err  +  d_acker_yaw·wz

The CL camber law: ff is a feedforward standing lean at the cell's λ; the PD terms trim it to track the yaw reference integrated from turn_rate (a reference shared with the diff arm); |lam_cmd| clamps to [gamma_acker_min 5°, gamma_acker_hi], and gamma_acker_limit 20° hard-clamps both channels (it is not open-loop-only). One layer down, the gait itself is open-loop template playback (v070 on its own clock) through the impedance layer, with only roll stabilized (k_roll 0.25, k_yaw 0.00 — yaw is deliberately free at the attitude level; turning belongs to the per-cell channel).

VALIDITY

What counts as a valid arc + how cells score

  • Arcs, not laps: 180–270° in the Vicon volume.
  • ≥ 180° heading over the steady band; fit arc ≥ 90°.
  • No 4 s window with v_fwd < 0.10 m/s; median v_fwd ≥ 0.85× the session straight baseline (the carry-in number).
  • Replacing sim self-certification: current logging on, bearing checked, config echoed (the tee).

Scoring: R_yaw = v_fwd / yaw rate primary, Kåsa circle fit beside it (band + fit arc quoted per run; Menger retired). Energy axis = ABAD current integral per arc — γ is not a controlled variable under the loop, so per-cell differences read on current, not γ medians; indistinguishable λ rows are themselves a result. Cross-track = Kåsa residual both arms; repeatability = sd(κ) over ≥ 5 arcs.

Free
P-HW-ρ on every λ cell (record body roll, IMU + Vicon — it is free): bar sign NEGATIVE, magnitude in [0.15, 0.65] °/°. It arbitrates the entire sim roll story and outranks everything except the matrix itself. Also free: per-leg β_TD at touchdown from the 1 kHz log on the straight-baseline runs (#20 trim; per-leg pooling with the dir_beta mirror — the §112 trap).
